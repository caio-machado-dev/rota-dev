# Rota Dev: web

Front-end em Next.js (App Router), TypeScript, Tailwind e shadcn/ui.
Como rodar e convenções: [README da raiz](../README.md) e [AGENTS.md](../AGENTS.md).

```bash
pnpm install
pnpm dev        # http://localhost:3000 (a API deve estar em http://localhost:8080)
pnpm test       # testes (Vitest)
pnpm lint && pnpm typecheck
```
